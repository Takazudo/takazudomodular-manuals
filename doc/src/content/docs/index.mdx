# zmanuals Documentation

Technical documentation for the **takazudomodular-manuals** project — a web-based viewer for hardware synthesizer manuals.

The site displays PDF manual pages alongside Japanese translations in a bilingual, searchable interface. It is built with zfb (Preact islands) and deployed on Cloudflare Workers at [manuals.takazudomodular.com](https://manuals.takazudomodular.com/).
